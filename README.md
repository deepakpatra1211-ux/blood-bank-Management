# Blood Bank Management System

## Project Overview
The Blood Bank Management System is a web-based application designed to manage blood donors, blood groups, blood requests, and blood bank information.

## Technologies Used
- HTML
- CSS
- JavaScript
- Bootstrap
- Python
- Django
- MySQL

## Features
- User-friendly interface
- Blood donor management
- Blood group information
- Blood request management
- Database integration

## Installation
1. Clone this repository.
2. Open the project folder.
3. Create and activate a Python virtual environment.
4. Install the required dependencies using `pip install -r requirements.txt`.
5. Run database migrations using `python manage.py migrate`.
6. Start the server using `python manage.py runserver`.
